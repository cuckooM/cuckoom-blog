# CuckooM Blog — UI 设计文档

> 文档版本: v1.0
> 创建日期: 2026-06-01
> 设计范围: 全站点页面重设计
> 基础主题: Hexo landscape（渐进式改造）

---

## 一、设计概述

### 1.1 设计目标
- 从陈旧的 landscape 默认主题升级为现代极简设计语言
- 核心变更: 固定边栏 → 居中卡片 + 可折叠侧栏抽屉
- 全站点支持深色/浅色模式无缝切换
- 保持 Hexo EJS + Stylus 技术栈，渐进式改造

### 1.2 设计原则
- **一致性**: 统一卡片、按钮、间距体系贯穿所有页面
- **可用性**: 清晰的导航路径和交互反馈
- **可访问性**: WCAG AA 对比度标准，键盘可达
- **响应式**: 320px–2560px 全分辨率适配
- **双语兼容**: zh-CN / en 切换后布局零差异

## 四、组件规范

### 4.1 导航栏 (Header / Navbar)

**用途**: 固定顶部导航，提供站点主要导航入口和操作按钮

**结构**:
```
+------------------------------------------------------------------------+
|  [Logo] CuckooM     首页  归档  分类  标签  关于     🌙  🌐  🐙  🔍   |
+------------------------------------------------------------------------+
```

**状态**:
- **默认**: 透明背景（Hero 上方叠加），文字颜色为白色（在渐变背景上）或主色
- **滚动后**: 背景色变为 `var(--color-card-bg)`，添加底部阴影 `0 1px 4px rgba(0,0,0,0.08)`，文字颜色变为 `var(--color-text-primary)`
- **移动端**: 隐藏导航链接，显示汉堡菜单按钮

**组件明细**:
- **Logo**: 左侧，文字 "CuckooM"，字号 20px，字重 700，点击返回首页
- **导航链接**: 水平排列，间距 24px，字号 15px，字重 500，当前页高亮（下划线 2px，颜色 `var(--color-primary)`）
- **操作图标组** (右侧):
  - 深色模式切换: 太阳/月亮图标，20px，点击切换
  - 语言切换: 🌐 图标或文字 "EN"/"中文"，点击弹出下拉
  - GitHub 链接: 🐙 图标，20px，新标签页打开
  - 搜索: 🔍 图标，20px，点击弹出搜索面板（或展开搜索框）

**滚动行为**:
- 使用 `position: sticky; top: 0`（推荐，避免 fixed 导致的布局跳动）
- 滚动超过 60px 后添加背景色和阴影（通过 JS 检测 scrollY 或使用 CSS `position: sticky` + `:not(:only-child)` 技巧）
- 过渡动画: 0.2s ease

### 4.2 Hero 区域

**用途**: 首页顶部展示博客品牌信息，建立视觉第一印象

**首页完整 Hero**:
```
+----------------------------------------------------------+
|                                                          |
|                                                          |
|                  CuckooM                                 |
|           技术笔记 · 思考记录 · 生活碎片                   |
|                                                          |
|      一个关于编程、技术和生活的个人博客                      |
|      A personal blog about coding, technology & life     |
|                                                          |
|                                                          |
+----------------------------------------------------------+
```

**组件明细**:
- **背景**: 线性渐变 `linear-gradient(135deg, var(--gradient-hero-start), var(--gradient-hero-end))`
- **高度**: 首页 45vh (max 360px, min 200px)，非首页 25vh (max 200px, min 120px)
- **文字颜色**: 白色 `#FFFFFF`（渐变背景上对比度 > 4.5:1）
- **博客标题**: 32px，字重 700，居中
- **副标题**: 18px，字重 400，opacity 0.9，居中，margin-top 8px
- **简介文字**: 15px，字重 400，opacity 0.8，居中，margin-top 16px
- **内边距**: 上下 64px，左右 24px

**非首页简化 Hero**:
```
+----------------------------------------------------------+
|                                                          |
|              归档 Archives                                |
|                                                          |
+----------------------------------------------------------+
```
- 高度: 25vh (max 200px)
- 仅显示页面标题，无副标题和简介
- 背景渐变同上

### 4.3 文章卡片 (Article Card)

**用途**: 首页、分类页、标签页的文章列表展示单元

**默认状态**:
```
+--------------------------------------------------------+
|  文章标题文章标题文章标题                                  |
|  2026-06-01  ·  技术笔记  ·  ☕ 5 分钟阅读                |
|                                                        |
|  这是文章的摘要文本，显示前 2-3 行内容。摘要文本用于帮助  |
|  读者快速了解文章大意，决定是否继续阅读...                 |
|                                                        |
|                          #Hexo  #JavaScript  [阅读更多 →] |
+--------------------------------------------------------+
```

**Hover 状态**:
- 卡片上移 2px (`transform: translateY(-2px)`)
- 阴影增强: `0 4px 16px rgba(0,0,0,0.12)`
- 过渡: 0.2s ease

**组件明细**:
- **标题**: 20px，字重 600，颜色 `var(--color-text-primary)`，hover 变链接色
- **元信息行**: 13px，颜色 `var(--color-text-secondary)`，元素间用 `·` 分隔
  - 日期: `YYYY-MM-DD` 格式
  - 分类: 分类名称（链接）
  - 阅读时长（可选）: `☕ N 分钟阅读`
- **摘要**: 15px，行高 1.6em，颜色 `var(--color-text-secondary)`，最多显示 3 行（`-webkit-line-clamp: 3`）
- **标签**: 13px，胶囊样式，背景 `var(--color-tag-bg)`，文字 `var(--color-tag-text)`，圆角 4px，内边距 4px 8px
- **阅读更多按钮**: 右对齐，文字色 `var(--color-primary)`，字号 14px，字重 500，hover 时文字色加深
- **卡片内边距**: 24px
- **卡片间距**: 32px（卡片之间）
- **卡片背景**: `var(--color-card-bg)`，圆角 12px

**布局**:
- 桌面端: 单列居中，max-width 720px
- 移动端: 单列全宽（减去左右 padding 16px）

### 4.4 可折叠侧栏抽屉 (Sidebar Drawer)

**用途**: 提供分类、标签、归档、最新文章等导航入口，默认收起

**收起状态**:
- 仅在 Header 右侧显示一个 "☰" 按钮（侧栏展开触发器）
- 页面内容区无侧栏占用空间

**展开状态（桌面端）**:
```
+----------------------------------------------------+------+
|                                                    | 分类  |
|                    主内容区（变暗遮罩）               |  技术  |
|                                                    |  生活  |
|                                                    |  ------ |
|                                                    | 标签云 |
|                                                    | #Hexo  |
|                                                    | #JS    |
|                                                    |  ------ |
|                                                    | 归档   |
|                                                    | 2026   |
|                                                    | 2025   |
|                                                    |  ------ |
|                                                    | 最新文章 |
|                                                    | ...    |
+----------------------------------------------------+------+
```

**展开状态（移动端）**:
- 全屏覆盖（从右侧滑入），带半透明遮罩
- 点击遮罩或侧栏内 "×" 按钮关闭

**组件明细**:
- **抽屉宽度**: 桌面端 300px，移动端 100%
- **抽屉背景**: `var(--color-card-bg)`
- **抽屉阴影**: `−4px 0 24px rgba(0,0,0,0.12)`
- **动画**: 0.3s ease-out，桌面端从右侧滑入，移动端从右侧覆盖
- **遮罩**: 背景 `rgba(0,0,0,0.3)`，点击关闭
- **Widget 间距**: 32px
- **Widget 标题**: 16px，字重 600，颜色 `var(--color-text-primary)`，下边框 `var(--color-border)`
- **Widget 列表项**: 14px，颜色 `var(--color-text-secondary)`，hover 变主色
- **关闭按钮**: 右上角 "×"，24px，颜色 `var(--color-text-secondary)`

**侧栏 Widget 内容**:
1. **分类列表**: 分类名 + 文章数徽章（如 "技术笔记 (4)"）
2. **标签云**: 标签按大小排列（文章数越多字号越大），最小 12px，最大 18px
3. **归档**: 按年月分组（如 "2026 年 6 月 (2)"）
4. **最新文章**: 最近 5 篇文章标题，14px，链接

### 4.5 深色模式切换按钮

**用途**: 手动切换深色/浅色主题

**设计**:
- 图标: 太阳 ☀️（浅色模式下显示，点击切换为深色）/ 月亮 🌙（深色模式下显示，点击切换为浅色）
- 尺寸: 20px × 20px
- 位置: Header 右侧操作图标组
- 切换动画: 图标旋转 180° + 淡入淡出，0.3s ease

### 4.6 语言切换器

**用途**: 中英文双语切换

**设计**:
- 默认显示: 当前语言的对立语言缩写（中文模式下显示 "EN"，英文模式下显示 "中文"）
- 点击: 直接切换到对立语言（简化交互，去掉下拉菜单）
- 位置: Header 右侧，深色模式切换按钮旁
- 样式: 文字按钮，字号 14px，字重 500，颜色 `var(--color-text-secondary)`，hover 变主色

### 4.7 搜索面板

**用途**: 全文搜索，搜索已有文章

**设计**:
- **触发方式**: 点击 Header 搜索图标
- **展示方式**: 
  - 桌面端: Header 内展开搜索输入框（从图标扩展为输入框）

- **搜索结果**: 下拉列表，每项包含标题 + 摘要片段
- **空状态**: "没有找到结果" 提示
- **快捷键**: 桌面端 `/` 键聚焦搜索框，`Esc` 关闭

**搜索结果项**:
```
+--------------------------------------------------------+

### 4.9 按钮 (Button)

**用途**: 通用操作按钮（阅读更多、提交等）

**变体**:

| 变体 | 背景 | 文字色 | 边框 | 场景 |
|------|------|--------|------|------|
| Primary | `var(--color-primary)` | 白色 | 无 | 主要操作 |
| Secondary | 透明 | `var(--color-primary)` | 1px solid `var(--color-primary)` | 次要操作 |
| Link | 透明 | `var(--color-link)` | 无 | 文本链接式按钮 |
| Ghost | 透明 | `var(--color-text-secondary)` | 无 | 图标按钮 |

**状态**:
- 默认: 如上
- Hover: 背景加深 10% 或文字变深
- Active: 背景加深 20% 或缩小 1px
- Disabled: opacity 0.5，pointer-events: none

## 十一、验收检查清单

### 视觉验收
- [ ] 所有页面 Hero 区域渐变色一致
- [ ] 卡片样式统一（圆角 12px，阴影一致）
- [ ] 深色/浅色模式对比度 ≥ 4.5:1 (WCAG AA)
- [ ] 间距体系一致（4/8/16/24/32/48/64px）
- [ ] 字体大小层级清晰

### 交互验收
- [ ] Header 滚动变色平滑过渡
- [ ] 侧栏展开/收起动画流畅 (0.3s)
- [ ] 深色模式切换无闪烁
- [ ] 卡片 hover 效果正常
- [ ] 搜索防抖正常工作

### 响应式验收
- [ ] 320px: 无横向滚动，文字不溢出
- [ ] 768px: 布局自适应
- [ ] 1024px: 多列布局正确
- [ ] 1920px: 内容居中，不拉满

### 双语验收
- [ ] zh-CN / en 切换后布局一致
- [ ] 菜单文字正确切换
- [ ] Hero 副标题适配对应语言
- [ ] 空状态文案适配对应语言

### 功能验收
- [ ] `hexo generate` 无报错
- [ ] `hexo server` 预览正常
- [ ] 搜索功能正常
- [ ] 边栏展开/收起正常
- [ ] 现有文章渲染无异常
